# background-computer-use

Computer use for macOS agents that never takes your focus. Agents work in your real, logged-in apps, in windows on a virtual display you don't see, while you keep using your Mac. It runs as a menu bar app with a live preview of what the agent is doing.

No app is modified and nothing is app-specific: it uses only what macOS provides for every app (a virtual display, Accessibility, per-process input events, window capture).
